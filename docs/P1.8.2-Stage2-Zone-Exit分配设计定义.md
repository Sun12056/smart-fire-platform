## 3. 生产调用链

### 3.1 后端（Demo Engine，权威）

```

       persons: buildingPersons(world),
```

- 输入数据来源：`buildingPersons(world)`（后端 world 内人员）、`world.exits`（后端权威出口状态）。

### 3.2 前端（mock / 无后端）

```
  └─ planBuildingStrategies({ buildingId, buildingName,
       persons: buildingPlanningPersons(...), fire, maxFloor,
       strategies: [BALANCED, FASTEST, SAFEST] })
```

- **关键差异（源码事实）**：前端调用**未传 `exits`**，而 `planBuildingStrategies` 缺省 `exits = EXIT_DEFS`（全 OPEN）。这与 D-6=A「不接真实源」一致，但意味着 mock 路径的分配**不受运行态出口状态影响**。

| 关系 | 现状 |

## 5. 最小算法方案

### 5.1 现状结论（不重写的依据）

现有分配流程已闭环：**分组 → 候选生成 → 策略选择 → 顺序贪心负载均衡 → 校验**。在无 capacity / 拥堵 / 转弯 / 周转需求的前提下，这套流程已实现"每个 zone 分配一个合法出口"的语义。

### 5.2 Stage 2 范围（已裁定：S2-A）

经负责人裁定，Stage 2 采用 **S2-A（仅契约化，不重写算法）**。

**S2-A 的完成标准（非仅写文档）**：
1. 将 §5.3 的关键分配行为转化为**可执行的测试契约**（新增测试文件，见 §8.1）；
2. 证明现有 `pickRouteByStrategy` / `exitLoad` / `planBuildingEvacuation` 行为**符合**这些契约（实测 `npm run test:unit`）；
3. 测试数量不得减少、不得修改或跳过既有断言（见 §8.2）。

明确**不纳入** S2-A：S2-B 三态接线、S2-C 容量/评分（均留待后续或 P1.8.3）。

### 5.3 Zone→Exit 分配规则（现状契约化描述）

1. 每个「有人员的 floorId+zone」必须有一条且仅一条合法路线（终点为 1F 可用出口）。
2. 候选经 `findPaths` 过滤：不可用出口（`available=false` / `CLOSED` / `BLOCKED`）不进入候选目标。
3. 选路线规则由 strategy 决定（BALANCED / FASTEST / SAFEST）。
4. BALANCED 的负载均衡为**顺序贪心**：按分组排序逐个分配，负载差 ≥1 时走人少出口。
5. 无候选出口的 zone 计入 `missingZones`，方案 `valid=false`。

### 5.4 不可达 / 不可用 / 无候选的处理

| 场景 | 现状处理 | 是否需 Stage 2 补充 |
|---|---|---|
| 出口不可用（CLOSED / BLOCKED / available=false） | `isExitUsable` 过滤，不进入候选 | 已覆盖 |
| 出口不可达（拓扑不通） | `findPaths` 求不到路径 → 不产出候选 | 已覆盖，但**无三态区分**（reachable/blocked/unreachable 未接线） |
| 无候选出口（全不可用或全不可达） | `missingZones` + `valid=false` + 失败通知 | 已覆盖 |

## 7. 异常和边界场景

| 场景 | 现状 | 建议验收点 |
|---|---|---|
| 某 zone 无候选出口 | `missingZones` + `valid=false` | 断言失败通知触发 |
| 出口全不可用（blockAll 语义） | 属 Stage 1 失效层（`exitRuntime`），分配层产不出合法候选 | 与分配层边界不重叠，回归保持 |
| `capacity=null` | 不施加约束，大流量区域仍获合法路线 | 断言既有行为不变 |
| 走廊人员（无房间节点） | `resolvePlanningZone` 归到最近房间 zone | 覆盖测试 |
| 负载均衡顺序偏差 | 分组排序（楼层降序 + zone 字典序）决定分配顺序，可能产生非全局最优 | 记录为已知限制，不在此阶段优化 |
| 前端 mock 路径未传 exits | 回落全 OPEN | 记录为已知限制（D-6=A 一致） |
