### 2.3 备份哈希核验（**新增，失败即 throw**）

```powershell
$verify = foreach ($f in $files) {
  $a = (Get-FileHash -LiteralPath $f        -Algorithm SHA256).Hash
  $b = (Get-FileHash -LiteralPath (Join-Path $bk $f) -Algorithm SHA256).Hash
  [pscustomobject]@{ file = $f; original = $a; backup = $b; match = ($a -eq $b) }
}
$verify | Format-Table -AutoSize | Out-String | Set-Content (Join-Path $bk 'backup-verify.txt') -Encoding utf8
if ($verify.match -contains $false) { throw 'BACKUP MISMATCH：备份与原件不一致，停止实施' }
```

**核验判据**：11 项 `match` 全为 `True`，且 `backup-verify.txt` 落盘在 `$bk`（仓库外）。任一不一致 ⇒ 立即停止，不进入 S1。

### 2.4 保护对象快照（哈希集合判定，P-2 已认可）

```powershell

# ② 保护文件哈希
```

**判定规则（不变）**：以 `untracked-hashes.txt` 的**哈希集合**为准，**不以数量为准**。参考量级：本计划轮写入前实测 **28 项**；写入本文件后为 **29 项**。实施轮以 S0 当场采集的集合为基线，S7 复核时要求逐一哈希一致。
