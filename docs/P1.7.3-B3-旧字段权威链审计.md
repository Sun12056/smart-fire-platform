## ④ 必须修改的判定入口（建议改法）

统一引入 `shared/person/personRuntime.js` 的 `buildingIdOf / floorIdOf / zoneOf / buildingNameOf`，设备用 `shared/device/deviceRuntime.js` 的 `deviceInBuilding / deviceOnFloor / floorIdOf / zoneOf`：

| 场景 | 现在 | 改成 |
|---|---|---|
| 楼栋归属 | `x.building === buildingName` / `x.buildingId \|\| fireBuildingId(x.building)` | `buildingIdOf(x) === buildingId` |
| 楼层归属 | `x.floor === floor` / `x.floorId \|\| x.floor` | `floorIdOf(x) === floorIdOf({ floorId })` |
| 区域归属 | `x.area === zone` / `x.zone \|\| x.area` | `zoneOf(x) === zoneOf({ zone })` |
| 火灾三元组 | `fireBuildingId(fe.building)` / `fe.floor` / `fe.area` | `fe.buildingId` / `fe.floorId` / `fe.zone`（`buildingFireContext()` 直接返回 canonical） |
| 风险区域对象 | `{ building, floor }` | 补 `buildingId / floorId / zone`（别名保留） |

配套：`fireBuildingId(name)`（`fireStore.js:859-862`）在查不到时回退 `routeBuildingId.value`，建议内联为 `buildingIdFromName()`（找不到返回 `''`），避免“查不到就认当前楼栋”的串楼栋风险。
