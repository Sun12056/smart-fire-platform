
**关于口径的一处修正（重要）**：确认方案里写的「persons 全 normal / devices 回 daily / metrics 归零」，
按字面理解会让这三项全部判红，但实测**基线本身就带 36 名 `static` 静止人员、6 台 `offline` 离线设备、`total=90`**
（IDLE 时后台固有数据，非演练产物）。因此这三项的正确判据是「**回到基线**」而非「字面归零」，
脚本已改为自动取第 00 步基线值做对比——上面三行差均为 `[]`，即 RESET 确实完整复位。
