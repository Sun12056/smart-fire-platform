## A.5 基础组件与业务组件分层方案

```
L0  tokens.css                       —— 只含变量
L1  components/base/                 —— 无业务语义、可跨项目复用
    SfButton SfIconButton SfInput SfSelect SfTextarea SfCheckbox
    SfTag SfBadge SfCard SfPanel SfDialog SfTooltip SfEmpty SfSpinner
    SfTable(prepare) SfPagination
L2  components/patterns/             —— 平台级组合，含平台语义但无消防业务
    SfPageHeader（标题+副标题+装饰条+右侧操作）
    SfPanelHeader（标题+图标+操作区）
    SfStatusDot / SfStatusTag（统一状态色）
    SfStatCard（复用孤立 StatCard 的意图）
    SfToolbar / SfSegmentedTabs / SfLegend / SfFlowSteps
L3  components/business/             —— 消防业务组件
    FloorPlanCanvas（唯一 2D 平面图承载）
    EvacDirectionBadge（统一走 resolveDirectionDisplay）
    RouteVerdictNote（来源文案统一走 overrideSourceLabelOf）
    RouteLayerLegend（正常/阻断/未知 三态）
    DeviceStatusList / EvacPlanSelector / DemoModeBanner（合并 DemoBadge 与 DataSourceBanner 的同类职责）
```

**分层纪律**

1. **L1 不得 import store / api**；L2 不得 import 消防业务 store；L3 才允许。
2. 响应式尺寸与主题只允许通过 L0 令牌表达，禁止组件内出现色值/字号字面量。
3. 状态语义（`resolved/overridden/conflict/undetermined/unlinked/none/remote`）是**业务枚举**，只能来自 `deviceDirection.js`，组件不得自造状态。
4. 迁移纪律：**新代码必须用 L1/L2；旧代码"触碰即迁移"**，禁止"大爆炸重写"。
5. `StatCard`/`BuildingMap`/`BuildingMiniature`/`AlarmList` 四个孤立组件的去向在 S-02 开单裁决（复用 / 删除，删除须单独授权）。
