### 1.1 基线采集命令（PowerShell，只读）

### 1.2 判定口径（全部满足才可进 S1，否则**停止并报告**）

| 项 | 期望 |
|---|---|
| 分支 | `main`（若已变化，停止） |
| HEAD | 与「设计/计划轮记录的 SHA」一致；本计划记录值 `7d77a6ea89f1d390f334bcaddfea997ab929f931`。若 HEAD 已前进（他人提交），**不自行判断可继续**，须先报告并重新对齐行号 |
| 暂存区 | 空 |
| `vite.config.js` | `git hash-object` 结果 == `git rev-parse HEAD:vite.config.js`（内容零差异）；`diff --numstat HEAD` 为空 |
| `worker/src/**` | `status` 与 `diff --stat` 均为空 |
| `git diff --check` | 无输出、退出码 0 |

### 1.3 保护对象快照（写入**仓库外**，避免污染未跟踪集合）

```powershell
$bk = Join-Path $env:TEMP ('p182-r01r11-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
New-Item -ItemType Directory -Path $bk | Out-Null
# ① 待改 6 个文件的原始副本（回滚依据）
Copy-Item shared/evacuation/deviceDirection.js, src/stores/fireStore.js, src/views/BuildingView.vue,
          src/components/building3d/EmergencyLight3D.js, src/components/building3d/building3dUtils.js,
          src/views/EvacuationView.vue -Destination (Join-Path $bk 'src')
# ② 未跟踪文件清单 + 逐个哈希（保护依据，不搬移、不改动）
git status --porcelain=v1 -uall | Select-String '^\?\? ' | Out-File (Join-Path $bk 'untracked-list.txt') -Encoding utf8
git ls-files --others --exclude-standard | ForEach-Object { (git hash-object $_) + '  ' + $_ } |
  Out-File (Join-Path $bk 'untracked-hashes.txt') -Encoding utf8
# ③ 保护文件的哈希
Get-FileHash vite.config.js | Out-File (Join-Path $bk 'vite-config-hash.txt') -Encoding utf8
```

**保护集合的判定规则**：以 **`untracked-hashes.txt` 的哈希集合**为准，**不以数量为准**。计划轮开始时实测为 **27 项**；本计划文档写入后会 **+1**（即 28 项）。实施轮必须以 S0 当场采集的集合为基线，逐项比对「内容哈希未变」，而不是比对数字。

### 1.4 未跟踪文件的处理规则（硬性）

1. **禁止**删除、移动、重命名、覆盖、`git add`、`git clean`、`git stash`；
2. 禁止把手工验收截图、临时日志、脚本产物写入仓库（一律写 `$env:TEMP`）；
3. 实施过程中若发现未跟踪文件数量变化，先判断是否为自己新增（本批只允许新增：T3 测试文件、实施报告），其余变化**立即停止并报告**；
4. `$null`、`worker/e2e-journey-exit.log'` 等历史遗留项**保持原样**，不清理、不纳管。

### 1.5 回滚的总则（贯穿全部步骤）

- 回滚 = **从 `$bk\src` 恢复对应文件的原始副本**，或按 git diff 逐行反向编辑；
- **禁止**使用 `git checkout` / `git restore` / `git reset` / `git stash`（会波及其他未提交改动，亦未获授权）；
- 每步回滚**只回滚该步的文件**，不连带回滚其他步骤；
- 回滚后必须复跑该步的针对性测试与 `git diff --check`，并在报告中如实记录回滚原因。
