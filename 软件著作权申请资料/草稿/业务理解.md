# 业务理解

- 软件名称：智慧消防数字孪生管理平台
- 产品定位：面向消防管理与楼宇安全的纯前端智慧消防可视化平台，以“楼宇数字孪生 + 火情应急闭环”为核心，提供态势总览、设备告警、疏散引导、路径规划、设备管理与远程巡检的一体化演示与值守能力。
- 面向领域 / 行业：消防安全 / 智慧应急 / 城市与楼宇安全（可归口为消防安全管理类软件）
- 核心价值：把分散的消防设备、人员与告警集中到同一张“楼宇数字孪生”图上，用一套六阶段火情应急闭环（发现—响应—规划—疏散—识别—救援）把监测、告警、疏散、设备、照明、巡检串成可演示、可追溯的整体，降低值守与演练门槛。
- 证据文件：`业务理解证据.md`

## 目标用户

- 消防值班与指挥
- 物业/楼宇安全
- 应急管理

## 主要业务功能

- 楼宇态势（数字孪生监控）
- 智能告警（告警中心与七步处置）
- 智能疏散（疏散引导）
- 疏散路径（路径规划）
- 智能设备（设备管理与远程配置）
- 智能照明（照明联动控制）
- 远程巡检（巡检中心）
- 后台日志（操作日志审计）

## 功能说明

- 楼宇态势（数字孪生监控）：以楼层平面图数字孪生方式总览楼宇消防态势，支持楼栋总览、楼层网格、单层放大平面图三级视图切换，呈现设备节点、人员感知、火源热区、疏散路线，并联动六阶段应急处置进度。
- 智能告警（告警中心与七步处置）：集中展示消防设备告警，支持按全部/待处理/处理中/已解决筛选，查看详情并执行“发现异常→平台研判→告警确认→任务派发→现场处置→结果复核→事件关闭”的七步标准处置流程。
- 智能疏散（疏散引导）：在应急状态下动态控制楼层疏散指示灯方向（左/右两向），将人员引导至安全出口，统计区域内在岗与疏散人数，应急模式下路线避让火源通道切换至安全出口。
- 疏散路径（路径规划）：自动或手动规划火灾下的疏散路径，标记推荐实线、备用虚线、火灾禁行红虚线，支持人工增删路径节点与起止点，确认执行后联动平面图与疏散流程。
- 智能设备（设备管理与远程配置）：管理消防设备台账，按类型/楼栋/楼层/状态/关键词筛选，查看设备详情、下发远程配置（开关、亮度、功率、阈值等）并查看历史数据曲线。
- 智能照明（照明联动控制）：基于人员感知联动控制楼层照明，支持亮度调节与节能/人员感应/应急三种模式切换，展示亮度变化趋势与能耗统计，应急时一键全亮至100%。
- 远程巡检（巡检中心）：对消防设备发起远程自动化巡检，逐步执行巡检步骤并实时显示进度，汇总通过/警告/异常结果，生成巡检报告并归档历史记录供追溯。
- 后台日志（操作日志审计）：以时间轴方式记录平台全部操作与事件（信息/警告/成功/危险四级），供管理员与审计人员追溯平台运行过程。

## 典型操作流程

1. 常规监测：平台常态展示楼宇态势、设备状态与告警，每5秒自动更新模拟数据（Mock）。
2. 发现火情：定位建筑/楼层/区域（默认3号楼5F A区），平面图标记火源热区，联动应急照明、标记危险区与风险人员。
3. 启动应急响应：自动计算疏散路线，告警升级，生成后台操作日志。
4. 生成多套疏散方案：按A/B/C/D四区生成多套疏散方案（距离、预计时间、出口、风险），指挥人员点选方案联动平面图执行疏散。
5. 智能疏散：疏散指示灯脉冲强闪，人员沿路线撤离，实时统计待疏散/已疏散/总数及进度。
6. 滞留人员识别：疏散完成后识别并确认滞留人员位置，标记危险警告。
7. 协同消防救援：启动救援协同、标记救援资源，救援完成后关闭事件。
8. 日常运营：设备筛选与远程配置、告警七步处置、照明调光与模式切换、远程巡检与报告归档、后台日志审计，与上述应急闭环并行使用。

## 操作手册页面/流程模块

1. 楼宇态势（数字孪生监控）：左侧导航“楼宇态势”，或应用启动后默认重定向至此页（路由 /dashboard）。
   - 使用场景：监控中心常态值守时，查看某栋楼某层的实时消防态势；演练或真实火情时逐级查看建筑—楼层—平面图，掌握火源、人员与疏散路线。
   - 操作要点：选择楼栋与楼层。；在楼层网格点击进入放大平面图，或用芯片切层、缩放平移。；观察火灾热区脉冲、疏散路线（推荐实线/备用虚线/火灾禁行红虚线）、设备与人员节点动画。；进入应急阶段后，右侧面板按阶段显示疏散方案决策/疏散进度/滞留人员/协同救援，点选疏散方案联动平面图。
2. 智能告警（告警中心与七步处置）：左侧“设备管理”分组下的“智能告警”（路由 /alarms）。
   - 使用场景：值班人员收到告警后，进入告警中心筛选待处理告警，逐级处置并跟踪进度。
   - 操作要点：点击统计卡筛选告警范围。；在列表点击某条告警“操作”打开详情。；按时间线查看七步处置节点。；pending 点“开始处置”→processing（进度30%）；点“模拟派单”（进度50%）；点“提交复核”→reviewing（进度80%）；点“完成处置”→resolved（进度100%）。
3. 智能疏散（疏散引导）：左侧导航“智能疏散”（路由 /evacuation）。
   - 使用场景：应急疏散阶段，疏散指挥人员针对某楼层疏散指示灯下发左/右方向切换，确认指示灯指向安全出口、避开火源通道。
   - 操作要点：选择楼栋（固定3号楼）与楼层。；查看当前疏散指示灯方向与人员分布。；点击方向按钮（左/右）下发切换，约900毫秒后显示“方向切换成功”。；应急模式下路线由A区通道切换至B区通道右侧出口。
4. 疏散路径（路径规划）：左侧导航“疏散路径”（路由 /route-plan）；楼宇态势页“疏散路线规划”按钮也可跳转。
   - 使用场景：应急指挥人员规划从起火区域到安全出口的疏散路径，确认方案后下发到设备/平面图联动。
   - 操作要点：选择起火楼层与区域。；点击自动规划生成推荐/备用/禁行路线。；（可选）进入手动编辑，增删路径节点、设置起止点。；点“确认执行”将方案下发，平面图与疏散流程联动。
5. 智能设备（设备管理与远程配置）：左侧“设备管理”分组下“设备状态”（路由 /devices）。
   - 使用场景：运维人员检索某类设备、查看在线/离线状态，远程下发配置并查看该设备历史数据曲线。
   - 操作要点：用筛选区按类型/楼栋/楼层/状态或关键词检索设备。；点击列表某设备打开右侧详情与配置面板。；调整参数或开关，点“保存”/“下发”。；查看该设备历史曲线。
6. 智能照明（照明联动控制）：左侧“设备管理”分组下“智能照明”（路由 /lighting）。
   - 使用场景：运维或安管人员针对某楼层照明设备调光、切换模式，应急时一键启动消防应急照明（全亮100%）。
   - 操作要点：选楼栋→楼层→照明设备（联动默认选中首个）。；拖动亮度滑块调节，或点模式按钮切换节能/人员感应/应急。；点“启动应急模式”一键全亮100%并通知；点“模拟人员进入”联动提亮至85%；点“恢复默认”回节能模式。；查看右侧亮度趋势与能耗统计。
7. 远程巡检（巡检中心）：左侧“设备管理”分组下“远程巡检”（路由 /inspection）。
   - 使用场景：巡检人员选择设备发起巡检，跟踪执行进度，查看通过/警告/异常结果并生成报告。
   - 操作要点：选择巡检设备。；点“开始巡检”，步骤逐条执行（约1.2–2秒/步）。；进度条与节点状态实时更新。；完成显示结果（通过/警告/异常）与逐项明细。
8. 后台日志（操作日志审计）：左侧导航“后台日志”（路由 /emergency）；原“应急救援”已重构为此页。
   - 使用场景：管理员或审计人员查看平台运行期间产生的操作记录（信息/警告/成功/危险四级）。
   - 操作要点：进入页面查看按时间倒序的操作记录。；按等级颜色或模块区分事件类型。；点“清空日志”清空全部记录（store.operationLogs = []）。
